# ML Project Template

A production-ready template for Machine Learning and Data Science projects with CI/CD.

## Features

- Standardized project structure
- Config management with environment variables
- Testing with pytest
- Linting with Ruff and Black
- GitHub Actions for CI/CD

## Project Structure

```
ml-project-template/
├── data/                 # Data files (gitignored)
├── models/               # Trained models (gitignored)
├── notebooks/            # Jupyter notebooks
├── src/                  # Source code
│   └── __init__.py
├── tests/                # Unit tests
│   └── test_basic.py
├── .env.example
├── .gitignore
├── requirements.txt
└── README.md
