- Built a retrieval-based + fine-tuned chatbot for empathetic conversations
- Integrated mood tracking with interactive dashboards
- Hosted on Streamlit Cloud for public access
- Used TextBlob + custom NLP for sentiment-aware responses

### 2. [Nmap GUI](https://github.com/raghunath485/nmap_gui_project)
> A **graphical interface for Nmap** that simplifies network scanning and port analysis.

- Tkinter-based GUI wrapping Nmap CLI commands
- Supports scanning, service/version detection, OS fingerprinting
- Results exported to CSV/HTML for reporting
- Real-time scan progress visualization

### 3. Data Science / Machine Learning Project

- Feature engineering, hyperparameter tuning, model comparison
- Visualized insights with Matplotlib and built reusable preprocessing modules
